# Ichigo

An ocean adventure about a young child in a wooden bucket, with tactile fishing, wildlife, puzzles, chance-based discoveries, and a strongly authored visual identity.

Current phase: a runnable **P1 camera study** in Godot 4.7.2. It includes temporary child/bucket/fish forms, calm water, sky, adjustable camera pitch, steering, and line-target placement. Gameplay systems and final art are not implemented yet.

Launch with `./scripts/run_game.sh` or double-click `Run Ichigo.command`. See [prototype controls and setup](game/README.md).
